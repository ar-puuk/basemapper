basemapper

A headless spatial basemap renderer for R and Python.
Fetch and composite styled map tiles into RGBA arrays — no browser, no display server, no GDAL.

Install

R

remotes::install_github("ar-puuk/basemapper", subdir = "r-basemapper")

Requires ggplot2 ≥ 3.4, sf ≥ 1.0, jsonlite ≥ 1.8. Optional: tmap ≥ 4.0, stars ≥ 0.6 for tm_basemap(). CRAN and R-Universe packages planned after extended testing.

Python

pip install "basemapper @ git+https://github.com/ar-puuk/basemapper#subdirectory=py-basemapper"

Requires numpy, pyproj, matplotlib, requests. Optional: plotnine ≥ 0.12 for geom_basemap(). PyPI and conda packages planned after extended testing.

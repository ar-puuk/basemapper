Module tile_style

Expand description

Styles for tile data: anything a user may pass as style that is not itself a style. MapLibre always needs a style; when it is given a tile URL, a TileJSON, a PMTiles archive or an ArcGIS service instead, the style is built here, the way one would write it for MapLibre:

InputDetected byStyle
*.pmtiles (URL, path) / pmtiles://the archive header’s tile typeraster layer / default vector style
tile template ({z}, {quadkey}, …)extension, else one probed tileraster layer / default vector style
TileJSON URL or filevector_layers, formatraster layer / default vector style
.../MapServerURLraster layer over tile/{z}/{y}/{x}
.../VectorTileServerURLthe service’s published style
style URL or filelayers in the JSONthe style, relative URLs made absolute

The default vector style draws every source layer: polygons as translucent fills, lines and outlines, points as circles, a colour per source layer, over a transparent background (ready to stack).
